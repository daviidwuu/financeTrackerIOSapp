# FinanceTracker (wym)

FinanceTracker (wym) is a comprehensive personal finance management iOS application built with **SwiftUI** and **Firebase**. It allows users to track expenses, manage budgets, split bills with friends, and gamify their financial habits.

## 🚀 Getting Started

1.  Clone the repository.
2.  Open `FinanceTracker.xcodeproj` in Xcode.
3.  Ensure you have `GoogleService-Info.plist` (contact project lead if missing).
4.  Build and Run.
