# Figma Design System Documentation

This folder contains the complete design-to-code bridge for the FinanceTracker iOS app. Use these documents to ensure 100% fidelity when migrating or updating Figma designs.

## Contents

1.  **[Design Specification](design_spec.md)**: Every color, spacing value, and typographic style used in the SwiftUI codebase.
2.  **[Migration Checklist](migration_checklist.md)**: A readiness guide for ensuring all UI states (empty, loading, error) are accounted for in Figma.
3.  **[LLM Handoff Instruction](llm_handoff.md)**: A machine-readable guide designed for another LLM to orchestrate the Figma setup and prototyping flows.

## Core Tokens
- **Grid**: 4pt / 8pt
- **Primary Font**: SF Pro / SF Pro Rounded
- **Main Margin**: 20pt
